Notation: a small Python subset that Velme translates; it never runs as Python.
- Statements: `name = expr` (each name assigned once), `return expr`, and `if`/`elif`/`else` whose branches end in
  `return`. Indent with spaces. No loops, `def`, `import` or other statements.
- Names: an input or call result by its name, a field as `x.field`, a record as `Type(field=expr, ...)` with every
  field.
- Values: numbers such as `12` and `0.05` are exact decimals; Text "..."; `True`, `False`, `None`; lists `[a, b]`.
- Operators: `+ - * /` on Numbers only (`/` is decimal, never integer or float division), comparisons (chains too),
  `and`, `or`, `not`, `a if c else b`, `x in xs`, `x is None` for an optional `x` (it doesn't narrow `x`: read
  `unwrap_or(x, d).f`). No `**`, `%` or `//`. Conditions are Booleans, with no truthiness: test a list with
  `len(xs) == 0`.
- Lists: `[e for x in xs if c]`, `sum(e for x in xs)`, `all(c for x in xs)`, `any(c for x in xs)`,
  `next((x for x in xs if c), None)`, `sorted(xs, key=lambda x: k, reverse=True)` (Number keys),
  `reduce(lambda acc, x: e, xs, init)`, `len(xs)`, `unwrap_or(x, default)`.
- Calls: only the builtins below, with positional arguments. No methods (`x.f()`), f-strings, subscripts, dicts, sets
  or tuples, except `x in (a, b)`. `round(x)` gives a whole number, halves away from zero; to cents
  `round(x * 100) / 100`. Join Text with `concat`; make a Number Text with `to_text`.
