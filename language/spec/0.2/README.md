# Velme 0.2 Language Specification

This directory is the versioned mirror of the language chapters of the Velme specification
(`docs/spec/language/*.md`) for release `0.2.0-alpha.1` / language version `0.2` (R-REL-02).

It contains:
- `10-syntax-grammar.md` — Syntax and grammar
- `11-types.md` — Types and domain contracts
- `12-goals-calls.md` — Goals, bodies and composition
- `13-check-dsl.md` — Check DSL and examples
- `14-builtins.md` — Builtin catalog

Any change to `docs/spec/language/*.md` must be mirrored here byte-for-byte.

Links between these chapters work here. Links that leave the language chapters (`../SPEC.md`, `../compiler/…`,
`../runtime/…`) are kept byte-identical and resolve only in `docs/spec/language/`; follow them there.
